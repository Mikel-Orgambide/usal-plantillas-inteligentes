# Datos de prueba

Cada archivo declara su origen. `contract/` y `simulator/` contienen registros de ejemplo del contrato y la salida de referencia del simulador (procedencia `simulated`). `firmware/` guarda registros por USB de la placa con señal sintética. Los datos obtenidos con sensores están en `fisico/` (paquetes de sesión, CSV, informes PDF y registros del monitor serie), con fecha e identificador de sesión en el nombre. `remote/` reúne las comprobaciones del servicio remoto y `backup/` un paquete de respaldo.
