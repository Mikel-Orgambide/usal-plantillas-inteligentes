# Icon

Catorce iconos de trazo fino en retícula de 24px, trazo 1.5px (`icon-stroke`), extremos redondeados, sin relleno; heredan `color`. Nombres: `bluetooth`, `bluetooth-off`, `play`, `stop`, `history`, `compare`, `settings`, `check`, `alert`, `chevron-right`, `chevron-down`, `plus`, `search`, `foot`.

- Un icono no comunica estado solo: va con una palabra («Conectado») o un punto de estado.
- Tamaños: 24px en encabezado y filas, 20px dentro de botones y banners, 16px en chips (`size`).
- Decorativo por defecto (`aria-hidden`); pasar `label` cuando sea el único contenido de un botón.
