# Header

Encabezado de pantalla: un título en `title` (28/600) y una línea de contexto en `caption` con el punto de estado del dispositivo. Acción opcional a la derecha, siempre un icono de 24px en un botón secundario de 40px.

- `status`: `connected` (punto accent), `searching` (punto alert con pulso), `off` (anillo en text-secondary). El texto del contexto dice lo mismo con palabras: «Conectado · Plantillas-ESP32», «Buscando…», «Desconectado».
- Títulos: «Hoy», «Nueva sesión», «Grabando», «Sesión», «Historial», «Comparar».
- Padding `space-6` arriba, `space-4` abajo; sin fondo ni separador.
