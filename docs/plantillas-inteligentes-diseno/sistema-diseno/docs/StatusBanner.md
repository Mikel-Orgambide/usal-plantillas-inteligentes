# StatusBanner

Banner no intrusivo que informa un cambio de estado sin tapar la pantalla: `surface-elevated` para información, `alert-soft` con icono en alert para problemas. Texto en `label`, detalle opcional en `caption`, una acción textual opcional a la derecha.

- Grabación: «Conexión interrumpida» · detalle «Los valores en gris son anteriores a la desconexión» · acción «Reconectar».
- Inicio tras cierre inesperado: «Sesión recuperada como incompleta» · acción «Ver».
- Preparación: «Falta una posición» · detalle «L_LATERAL no responde».
- Nunca desaparece solo si el problema sigue; se va cuando el estado cambia.
